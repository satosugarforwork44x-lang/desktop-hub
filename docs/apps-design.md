# 設計メモ: ローカルアプリの紐づけ（次の MINOR で予定）

> 状態: 設計のみ。実装前に見直す。

## ねらい
Hub を「自作ツールの置き場」から「**PC の作業の起点**」にする。よく使うローカルアプリ（exe・ショートカット・フォルダ・スクリプト・URL）を
バーに並べ、ファイルをタイルに落とすだけで、そのアプリで開けるようにする。

## 使い方（案）
| 操作 | 結果 |
|---|---|
| `.exe` / `.lnk` をバーの「＋」へドロップ | アプリのタイルが増える（アイコンは exe から取り出す） |
| タイルをクリック | アプリを起動（起動中なら前面に出す） |
| ファイルをタイルへドロップ | そのアプリでファイルを開く |
| タイルを右クリック | 名前の変更・引数・作業フォルダ・外す |

## 作り（今の仕組みに載せる）
- モジュール `apps`（L2、`hub.multi: true`）。フォルダ窓と同じく、1 アプリ = 1 タイル
- 保存: `%LOCALAPPDATA%\Hub\data\hub.db`（store の `apps` スコープ）。設定ファイルには書かない
- 起動: `os.startfile` / `subprocess.Popen`（引数は配列で渡し、シェルを通さない）
- バーへのドロップ先の判定: バーの ＋ とタイルにドロップ受け口を付ける（今はパネルだけ）
- アイコン: `.lnk` の参照先・exe から Win32 `ExtractIconEx` で取り出して PNG にキャッシュ

## 安全
- 登録できるのは利用者がドロップした実在のファイルだけ。Claude（MCP）からは**起動させない**（道具として出さない）
- 引数のテンプレートは `{file}` だけを差し込む（L1 の actions と同じ書き方）

## 互換性
- `requires: { "hub": ">=0.6", "moduleApi": 1 }`。ホスト側の追加（バーへのドロップ受け口）は MINOR の範囲
