# フォルダ（folders）

## 何をするか
設定 `modules.folders.root` 直下のフォルダ1つを「レジストリ」として、1レジストリ＝1パネル窓で表示する。
エクスプローラーからドロップすると、そのフォルダへ**移動**する（コピーではない）。

## 操作
| 操作 | 方法 |
|---|---|
| 取り込む | エクスプローラーからパネルへドロップ。フォルダ行に落とすとその中へ、ファイル行に落とすとそのファイルと同じ場所へ |
| 開く | ダブルクリック（関連付けられたアプリで開く） |
| パネル内で移動 | 行をドラッグしてフォルダ行へ |
| 別のレジストリへ | 右クリック → 移動先 |
| 元に戻す | 見出しの ↶（直近30回分、レジストリごと） |
| 削除 | 右クリック → ごみ箱へ（完全削除はしない） |

## 設定
```json
"modules": { "folders": { "root": "~/Hub" } }
```
既定は `~/Hub`。初回起動時に作られ、空なら `Inbox` を1つ作る。設定画面から変更できる（再起動が必要）。

## 注意
- 同名のファイルがある場合は上書きせず「名前 (2)」にする。
- ドライブをまたぐ移動はコピー＋削除になるため、大きなフォルダは時間がかかる。
